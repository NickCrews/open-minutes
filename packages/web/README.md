# @open-minutes/web

The public transcript browser, built with [SolidJS](https://www.solidjs.com),
[TanStack Start](https://tanstack.com/start), Kobalte and Tailwind, and
deployed to [Cloudflare Workers](https://workers.cloudflare.com).

`pnpm dev` at the repository root runs it locally. Editing affordances, such as
renaming a person, are enabled only in dev. See
[docs/contributing/deploy.md](../../docs/contributing/deploy.md) for deploying.
