# @open-minutes/db

The [Drizzle](https://orm.drizzle.team) schema and migrations, database
connections, the `pnpm db` CLI, and the helpers that give each test its own
database. [`src/schema.ts`](src/schema.ts) is the data model.

See [docs/contributing/db.md](../../docs/contributing/db.md) for how
databases work in development, tests and production.
